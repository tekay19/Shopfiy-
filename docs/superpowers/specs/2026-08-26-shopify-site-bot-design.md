# Shopify Site Bot — Design

## Purpose

A local tool that lets the owner spin up new Shopify stores quickly, all
based on a single fixed theme ("Shopfinity"). The owner manually creates
each Shopify store and a custom-app Admin API token (store creation and
account verification are explicitly out of scope — automating those would
require bypassing Shopify's signup/anti-fraud controls, which this project
will not do). Once a store exists, the bot automates everything else:
theme install, brand customization, and AI-written content for products,
collections, and pages, driven from the owner's own product CSV.

## Scope

**In scope:**
- Local web UI (form) to connect to an existing Shopify store via Admin API
- Push the bundled Shopify theme (from the provided theme export) to that
  store via the Admin API
- Customize theme settings (store name, logo, primary color, hero copy)
  per store
- Import products from a standard Shopify product CSV, with AI-rewritten
  titles/descriptions/SEO fields matching a brand voice
- Auto-generate collections (grouped from CSV type/tags) with AI copy
- Auto-generate standard pages (About, Contact, Shipping & Returns) with
  AI copy
- Publish the uploaded theme as the store's live theme
- Live progress feed in the UI while a run executes
- Repeatable: the same tool is reused for every new store, one at a time

**Out of scope:**
- Creating Shopify accounts/stores or bypassing signup verification
  (phone/email/captcha) — this remains a manual step for the owner
- Multi-store queueing/batch runs (one store per run, run again for the
  next store)
- Product sourcing/scraping from external suppliers (products come from
  the owner's own CSV)
- AI-generated images/logos (logo is supplied by the owner as a file)
- Authentication/multi-user support (single local user, localhost only)

## Architecture

Node.js + Express local web app, run with `npm start`, used via
`http://localhost:3000` in the browser. No database — each run is
stateless aside from the theme template bundled in the project and an
`.env` file holding the OpenAI API key. The Shopify Admin API token is
entered per run in the form and never persisted to disk.

```
shopify-site-bot/
  server/
    index.js          Express app: serves the UI, POST /api/create-store,
                       GET /api/progress/:jobId (SSE)
    shopify.js         Admin API client: connection test, theme upload
                       (themeFilesUpsert), theme publish, asset upload
                       (logo), settings_data.json patching, product/
                       collection/page creation
    ai.js               OpenAI client: brand voice inference, product
                       copy rewriting, collection copy, page copy
    csv.js              Parses a standard Shopify product export CSV into
                       an internal product list
    theme-template/     Unpacked Shopfinity theme, bundled in the repo,
                       used as the upload source for every store
  public/
    index.html          Form: store domain, admin token + "Bağlan" button,
                       store name, logo upload, primary color, product CSV
    app.js              Form submission, SSE progress log rendering
  .env                  OPENAI_API_KEY
  package.json
```

## Data Flow

1. **Connect** — user enters store domain + Admin API token, clicks
   "Bağlan". Server calls a lightweight Admin API request (shop info) to
   validate the token and displays the shop name on success. Only then
   does the rest of the form (logo, color, CSV) become active.
2. **Submit** — user fills remaining fields and clicks "Mağazayı Oluştur".
   Server starts a job and streams progress back over SSE as each step
   below completes or fails.
3. **Theme upload** — all files under `server/theme-template/` are pushed
   to a new theme on the store via the Admin GraphQL `themeFilesUpsert`
   mutation (bulk upload, not one REST call per file).
4. **Brand customization** — logo file is uploaded as a theme asset;
   `settings_data.json` is patched with the logo reference, primary
   color, and store name/hero copy, then re-uploaded.
5. **Brand voice** — a single AI call infers a short brand tone (e.g.
   "premium minimalist", "playful budget") from the store name and the
   CSV's product types/tags. This tone is passed into every later AI
   prompt for consistency.
6. **Products** — for each CSV row, AI rewrites title/description/SEO
   fields in the brand voice (existing CSV values are the source
   material, not replaced from nothing); the enriched product is created
   via the Admin API with its variants and images.
7. **Collections** — products are grouped by CSV `Type`/`Tags`; each
   group becomes a collection with an AI-written description.
8. **Pages** — About Us / Contact / Shipping & Returns pages are
   generated by AI in the brand voice and created via the Admin API.
9. **Publish** — the uploaded theme is set as the store's main
   (published) theme.
10. **Done** — UI shows a run summary (counts of products/collections/
    pages created, any failures).

## Error Handling

- Each API-calling step (theme file batch, product create, collection
  create, page create) retries up to 3 times with backoff on failure.
- A single product/collection/page that still fails after retries is
  logged as failed in the progress feed and the run continues — one bad
  CSV row must not abort the whole store setup.
- Token validation failure at the "Bağlan" step stops before any
  destructive action is taken.
- The run ends with a summary line: totals created vs. failed, so the
  owner knows if anything needs manual follow-up.

## Testing

This tool's value is in real Admin API integration behavior, which isn't
meaningfully mockable. Testing approach:
- Unit tests for pure logic: CSV parsing (`csv.js`) and AI prompt
  construction (`ai.js`) — no network calls.
- End-to-end verification is manual: the owner runs a full store setup
  against a real (or Shopify Partner dev) store and confirms the theme,
  products, collections, and pages look right.

## Setup

`npm install`, set `OPENAI_API_KEY` in `.env`, `npm start`, open
`localhost:3000`. Per store: obtain an Admin API access token by creating
a custom app in that store's Shopify admin (Settings → Apps and sales
channels → Develop apps) with read/write scopes for themes, products,
collections, and pages, then paste it into the form.
